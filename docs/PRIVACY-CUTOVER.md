# Privacy cutover gate — draft implementation checklist

Current website notice describes Supabase EU/Ireland database storage. It remains unchanged in this development candidate because the production endpoint is unchanged. Before Google Sheets collection is enabled, replace that description with the actual data flow: browser → EU Supabase Edge function → Google Apps Script/Google Sheets, exact adult-only fields, server-generated consent time and notice version. Verify the actual service region/processing terms; do not assert EU-only Google storage without evidence.

The owner must supply/approve controller identity and contact, a concrete retention period, withdrawal/erasure contact, authorized team recipients, Google/Supabase provider disclosure and applicable transfer arrangements. Do not collect child information. Use an approved new notice version in public config, Edge secrets and Script Properties together. Keep collection gated off on the staged adapter until that notice is published. Deletion instructions and Google version-history caveat are in REGISTRATION-INTEGRATION.md. This draft is implementation documentation, not a newly approved privacy notice.
